# Banker's Algorithm and Page Replacement Algorithms

This folder contains implementations of Banker's Algorithm and page replacement algorithms studied in my Operating Systems (OS) course.

## Algorithms Included

### 1. Banker's Algorithm
- Used for deadlock avoidance.
- Checks whether the system is in a safe state before allocating resources.

### 2. Page Replacement Algorithms
- **FIFO (First In, First Out):** Replaces the page that entered memory first.
- **LRU (Least Recently Used):** Replaces the page that has not been used for the longest time.
- **MRU (Most Recently Used):** Replaces the page that was used most recently.
- **Optimal Page Replacement:** Replaces the page whose next use is farthest in the future, or that will not be used again.

## Purpose

The purpose of these implementations is to understand deadlock avoidance, memory management, and page replacement techniques in operating systems.
