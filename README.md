## Operating Systems Algorithms

This repository contains implementations of algorithms studied in my Operating Systems (OS) course.

## Topics Covered

- CPU Scheduling Algorithms
- Process Synchronization
- Deadlock Avoidance and Detection
- Memory Management
- Page Replacement Algorithms
- Disk Scheduling Algorithms
- Process Management

## Purpose

The purpose of this repository is to practice Operating Systems concepts, improve programming skills, and keep course algorithms organized for future reference and revision.

## Languages Used

- C++


## Repository Structure

Each topic is organized into a separate folder. Individual files contain the implementation of a specific algorithm.

## How to Run

Follow the instructions or compilation commands provided for each algorithm.

## Note

This repository is intended for educational purposes and is updated as I learn and implement additional algorithms.
